# ADR-0028: Freeze Approved Architecture Through ADR Governance

Status: Accepted
Acceptance date: 2026-08-04

## Context
A decade-lived product needs controlled evolution and traceable consequences rather than silent drift.

## Decision
Owner approval on 2026-08-04 froze this architecture package. Any architectural change must create or supersede an ADR and state context, decision, alternatives, tradeoffs, migration, data/event/plugin compatibility, testing, evidence, security, operational, schedule, roadmap, and milestone consequences. Update traceability and compatibility matrices with the decision.

## Alternatives
Informal documentation edits or code-first divergence.

## Tradeoffs
Decisions take deliberate review; urgent changes still require an expedited recorded ADR.

## Future impact
Unrecorded architectural divergence is a release blocker. Evidence of approval is retained under M0.
