# Husbandry Reference Provenance Gate

Reference schema, checksum, provenance, version, loading, and compatibility infrastructure is
qualified with non-production fixtures only. No real Snake or Spider husbandry statement is in the
production bundle. Guidance displays as unavailable until the owner separately approves the exact
source, publisher, publication/version/date, species/life-stage applicability, encoded guidance,
representation, and source conflicts.
