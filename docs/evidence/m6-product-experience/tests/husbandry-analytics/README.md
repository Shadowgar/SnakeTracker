# Husbandry Analytics and Estimates

Snake sheds and Spider molts remain separate capability-selected series; premolt observations are
not completed molt intervals. Deterministic suggestions use the bounded recent sample and
`median +/- max(MAD, 10% of median, one day)`. The suite covers short/long intervals, zero and
nonzero MAD, outliers, correction/void/reinstatement, insufficient history, passed windows, and
replay determinism. Every result is labeled an estimate; owner reminder schedules remain
authoritative.
