# M7 Recovery and Compatibility Evidence

Store backup/restore drills, key recovery, upgrade/downgrade, compatibility scan, plugin lifecycle, and restricted-mode evidence here.

## Raspberry Pi deployment qualification

Before actual Raspberry Pi deployment, retain the pinned native suite under `performance/pi/`.
The evidence must prove native Pi 5 execution, local SSD/ext4 placement, cold/warm performance,
CPU and memory budgets, thermal/throttling behavior, SQLite durability and restart persistence,
and coherent backup plus isolated restoration. Only a complete owner-reviewed suite grants
`Raspberry Pi deployment qualified`; ARM64 builds and development-host measurements cannot grant
that status.
